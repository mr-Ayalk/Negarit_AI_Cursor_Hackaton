# Negarit AI

Product-ready AI visiting guide for **Adwa Museum**.

One Next.js app (UI + API). Bluetooth hall detection, live voice guide, Telebirr shop/tips, coffee suggestions, visit story.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Visit flow

1. **Setup** — name, Bluetooth, microphone  
2. **Guide** — connects beacon network, welcomes you at Gateway  
3. **Walk halls** — enter 5gna Ber, 6gna Ber, Emperor Hall, Victory Court  
4. **Ask** — speak a question (voice → text → voice)  
5. **Shop / Tip** — Telebirr checkout  
6. **Story** — generate and share your day chronicle  

## Deploy (Vercel)

Import repo → Deploy (root is the app).
